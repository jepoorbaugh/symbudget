# Symbudget
## A Local First PWA budgeting tool

I'm positive this is not the first of its kind. But its a great way to have fun and learn about creating progressive web apps, and also to better allocate my money :)

Written in pure HTML/CSS/JS. 

# Installation
1. Clone this repo
2. That's it

# Running
Assuming you have python:
```shell
python -m http.server
```
Otherwise, use whatever http server you want.
